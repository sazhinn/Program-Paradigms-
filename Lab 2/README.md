# Лабораторная работа 2. Императивная парадигма

**Индивидуальный вариант:** 1 - банковский счет (снятие только при достаточных средствах).

## Состав
- `src/lab2.py` - задания 1-5, индивидуальный вариант и сравнительное задание.

## Запуск
```bash
python src/lab2.py
```
Программа по очереди запросит данные для заданий 2, 3 и варианта 1. Пример для задания 2: `2500`, `4`, `10`, результат: 10000, 1000, 9000.

## Задание 1. Таблица состояния

| Шаг | Команда | x |
|-----|---------|---|
| 1 | x = 10 | 10 |
| 2 | x = x + 5 | 15 |
| 3 | x = x * 2 | 30 |
| 4 | x = x - 8 | 22 |
| 5 | x = x // 2 | 11 |

x = x + 5 допустимо, потому что это не равенство, а присваивание: сначала вычисляется правая часть, потом результат записывается в x.

## Сравнительное задание

- **Где явно изменяется total?** В императивном варианте (`total = total + number`).
- **Где подробнее описано, как получить результат?** В императивном: цикл, условие и накопление записаны по шагам.
- **Какой вариант лучше показывает императивную парадигму?** Первый, с циклом for.
- **Как меняется total?** 0 -> 7 -> 17 -> 22 (прибавляются только 7, 10 и 5).
- **Разница в мышлении:** в императивном мы описываем как считать (по шагам), в декларативном что нужно получить (сумму положительных).

## Вывод

В моих программах состояние хранится в переменных (x, total, maximum, balance) и меняется командами присваивания. Условия решают, менять ли состояние (например, баланс уменьшается, только если средств достаточно), а циклы повторяют изменения для каждого элемента списка. Порядок команд важен: если поменять их местами, результат будет другим.

## Ответы на контрольные вопросы (кратко)

1. Императивная парадигма: программа это последовательность команд, меняющих состояние.
2. Состояние программы: значения всех переменных в данный момент.
3. Переменная хранит часть состояния.
4. Присваивание записывает вычисленное значение в переменную.
5. x = x + 1: взять старое x, прибавить 1, записать обратно.
6. Поток управления: порядок выполнения команд (последовательность, ветвления, циклы).
7. Условный оператор выбирает действие по условию.
8. for идёт по известному набору или числу повторов, while пока условие истинно.
9. Счётчик: переменная, которая считает количество (+1).
10. Накопитель: переменная, в которой собирается сумма или итог.
11. while бесконечный, если условие никогда не становится ложным.
12. Порядок важен, потому что каждая команда работает с состоянием после предыдущей.
13. Изменяемое состояние усложняет отслеживание и поиск ошибок.
14. Императивный описывает как, декларативный что нужно получить.
15. Какие шаги и в каком порядке нужно выполнить, чтобы получить результат.
